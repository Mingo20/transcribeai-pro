## El problema

Transcribir reuniones y entrevistas a mano toma horas.

## Qué hace

- Transcripción completa y resumen ejecutivo
- Plantillas de extracción de información
- Historial de transcripciones
- Exportación de resultados

## Cómo está construido

**Tipo:** PWA

Aplicación de una sola página con IA en el cliente.

**Tecnologías**

- HTML, CSS y JavaScript en un archivo
- Service Worker y manifest

**Backend**

- Ninguno propio

**Datos**

- Transcripciones locales

## Datos sensibles

Audios y textos potencialmente confidenciales.

## Reglas del proyecto

- Avisar al usuario si el audio sale del dispositivo
